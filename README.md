# Git Fundamentals – Starter Repo

Welcome! This repository is used for a short Git workflow exercise.
You will:
- Create a personal branch
- Update `intro.md` with a brief introduction
- Push your branch
- Open a Pull Request (PR) and assign the instructor (don-strong or donald.strong@skagit.edu) as a reviewer
- Do *not* merge your Pull Request -- it will be used for grading

## Assignment Steps (Short)
1) `git checkout -b firstname-lastname-dev`
2) Edit `intro.md` in the "Your Section" area
3) `git add intro.md && git commit -m "Add introduction ..."`
4) `git push -u origin firstname-lastname-dev`
5) Open a PR into `main` with the title "Added introduction - Firstname Lastname"
6) Assign the instructor as reviewer; leave PR open for grading
7) Submit the URL for your PR to Canvas for grading
See the full assignment sheet on Canvas for details (or the PDF provided).
